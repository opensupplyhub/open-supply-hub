__SUBHEAD__

What this page is for: OpenSupplyHub can search for every facility inside a boundary you give it — you paste a link and it draws the shape from coordinates baked right into that link's web address. There's no file upload; the shape is the link.

Why this takes any processing at all: the shape USGS publishes is built for scientific precision, not for pasting into a link — it can have thousands of corner points, and web addresses can only be so long before they stop working. Used raw, the link would either be too long to work or absurdly overdetailed for "roughly where the ground shook this hard," which is all a facility search needs.

What buffer and simplify do about that: buffer smooths the jagged, over-precise edges and pads them a little; simplify thins out excess corner points. Together they turn the raw scientific shape into something short enough to work as a link while still looking basically like the real shaking area.
